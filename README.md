# technext-presentations

Edit, add, fix, redesign or audit TechNext's interactive HTML presentations in the repo TechNextSG/technext-presentations (live, unlisted, at technextsg.github.io/technext-presentations). The decks are the company profile, portfolio, service showcase, marketing showcase, What is Odoo, the Odoo app series (Accounting, Sales, CRM), the ERP and marketing tier lists, client decks (Hitachi Elevator Philippines, JR-Tech Solution, BHD Asia · HummingBeing, HST Medical) and the launcher page. Covers the 1600x900 deck engine (builds, settle hooks for print, phone rotation, TV mode, presenter view), the Python build and its tokens, share links, PDFs, launcher thumbnails, the Drive mirror, TechNext's content and fact rules, and a QA gate. Use whenever the user asks to change, update, add, remove, check or reprint a TechNext presentation, deck, slide, proposal deck, PDF or the presentations launcher, including "edit all the presentations".

A Claude Code skill made by [TechNext](https://technext.asia). Read it online with every other TechNext skill:
https://technextsg.github.io/technext-claude-skills/#technext-presentations

## Install

```bash
git clone https://github.com/TechNextSG/claude-skill-technext-presentations ~/.claude/skills/technext-presentations
```

Then restart Claude Code. Update later with `git -C ~/.claude/skills/technext-presentations pull`.

This repo is generated from the working copy by `tools/build_skills.py` in
[TechNextSG/technext-claude-skills](https://github.com/TechNextSG/technext-claude-skills) and updates after every job.
Big render caches stay on the PC and are left out.
